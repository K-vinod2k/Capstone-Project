# Security Policy

## Supported Versions

Currently, only the main branch of this project is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Old     | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerabilities or API key leaks within this repository, please do **NOT** open a public issue. 
Private Vulnerability Reporting is enabled for this repository. Navigate to the `Security` tab in this GitHub repository and use the **"Report a vulnerability"** feature to disclose it privately to the maintainers.

We typically acknowledge reports within 48 hours.
